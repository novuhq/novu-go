# MarkAs

Mark all subscriber messages as read, unread, seen or unseen

## Example Usage

```go
import (
	"github.com/novuhq/novu-go/v3/models/components"
)

value := components.MarkAsRead
```


## Values

| Name           | Value          |
| -------------- | -------------- |
| `MarkAsRead`   | read           |
| `MarkAsSeen`   | seen           |
| `MarkAsUnread` | unread         |
| `MarkAsUnseen` | unseen         |
